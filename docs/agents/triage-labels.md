# 工单分流标签

工程技能提到分流角色时，使用表中对应的 GitHub 标签。

| 技能角色 | GitHub 标签 | 使用时机 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交给代理独立实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 维护者已决定不处理 |
