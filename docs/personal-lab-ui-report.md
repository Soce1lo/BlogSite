# 个人实验室 UI 与内容探索

2026-11-12

本次按「个人实验室：技术感更强，互动更丰富」调整网站。视觉与文案依据已有 About 和公开内容：研究型工程师、长期建设、从问题出发并用实践验证。

## 页面与功能

- 首页使用冷蓝色、无衬线标题、等宽标注和蓝图点阵。探索地图是主要视觉元素，周围保持克制，兼容亮色和暗色。
- 地图聚合知识系统、工程实践、家庭实验室三条主线；切换后显示该方向的最新记录，可继续进入长期主题列表。
- 首页保留最近输出、精选、长期主题和档案，增加工作方式、订阅入口；公开数量和最近发布日期由实际内容生成。
- 新增 `/explore/`：组合关键词、类型、主题、年份和排序，显示结果数量与空态。筛选状态保存在 URL，刷新及前进、后退时恢复。
- 阅读页增加估算时长、专注模式和链接复制。专注模式隐藏目录、延伸阅读和留言，保留正文与导航；复制不可用时提供可手动复制的链接。
- 六项导航适配手机；搜索快捷键按设备显示 `⌘ K` 或 `Ctrl K`。

## 数据与维护边界

继续使用 `isPublicEntry`、`resolveThreads`、`getPrimaryTopic` 与 `withBase()`。新增探索索引只投影公开标题、摘要、分类、主题、系列、标签、日期与路由；不输出来源路径或正文。没有读取或改动真实 Vault，没有新增依赖或执行同步。

主线定义在 `src/data/site-profile.ts`；地图最多展示前三条具有公开内容的主线。颜色集中在 `src/styles/tokens.css`。地图、探索与阅读控件均采用渐进增强：脚本不可用时仍保留静态文章入口和正文，交互控件隐藏。

## 验证结果

- `pnpm test`：83 / 83 通过。新增合成用例覆盖非公开条目过滤、组合筛选、Unicode、稳定排序及 URL 往返；复用合成构建验证探索页的公开边界和 Pages 链接。
- `pnpm check:publish`：扫描 25 个文件，0 errors、0 warnings。
- `SITE_URL='https://soce1lo.github.io' BASE_PATH='/BlogSite' pnpm build`：32 页，Astro check 为 0 errors、0 warnings、0 hints。
- 生产 HTML 检查：首页、探索页和 I2C 阅读页的站内链接与脚本路径保留 `/BlogSite/`，无 `sourceVaultPath` 或本机路径。探索页静态输出 21 条公开记录，排除草稿和未列出示例。
- 浏览器检查：桌面明暗主题、地图切换、390px 手机筛选、320px 窄屏无横向溢出、空结果、后退与刷新恢复、搜索及 Escape、专注模式开关、复制成功提示。
- 无障碍复核：专注按钮保持稳定名称，以 `aria-pressed` 表示状态；复制状态节点始终留在无障碍树中。未进行真人读屏器验收。

阅读时间为粗估。当前关键词搜索使用公开元数据，不搜索全文；输入后在同一会话清空关键词，可能留下相同 URL 的相邻历史项。
